# transformer-demo

## 说明

为了学习 transformer，参考[这篇知乎](https://www.zhihu.com/question/445556653/answer/1903236419587126696)写的，写一个 demo，实现一个简单的 transformer 架构。

## 环境安装
```powershell
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
pip install -r requirements.txt
```
